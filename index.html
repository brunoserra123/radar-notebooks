⚡ 1. Tecnologias de Memória RAM: Qual a diferença?

DDR5 (Padrão Gamer Atual)
4800 a 5600 MHz

Padrão de alta velocidade com dois subcanais de 32 bits independentes por pente. Entrega até +50% de largura de banda para o processador comparado ao DDR4, mantendo os FPS mínimos mais estáveis.

✅ Vantagem: Usa pentes SODIMM removíveis (fácil upgrade até 64GB).
LPDDR5X (Ultrafinos / Estilo Mac)
7467 MHz

Velocidade absurda e baixo consumo elétrico, porém vem 100% SOLDADA na placa-mãe. Não existem slots físicos!

❌ Atenção: Se comprar com 16GB, vai morrer com 16GB. Não aceita troca! (Ex: Zephyrus G16).
DDR4 (Geração Passada)
3200 MHz

Tecnologia de gerações anteriores (2020-2023). Mais barata, mas com menor largura de banda. Praticamente extinta em notebooks gamer modernos de R$ 8.000+.

⚠️ Evite em compras novas acima de R$ 7.000.

💾 2. Armazenamento: O que aconteceu com o HD SATA 2.5" e M.2 NVMe?

✅ Padrão Moderno 2x Slots M.2 NVMe PCIe 4.0

Todos os notebooks gamer atuais adotam dois slots M.2 NVMe.

  • ✓ Velocidades brutais: 5.000 a 7.500 MB/s (14x mais rápido que qualquer SSD SATA).
  • ✓ Slot livre para 2º SSD: Você pode espetar um segundo SSD M.2 (1TB ou 2TB) a qualquer momento sem remover o original com o Windows!
  • ✓ Compacto no chassi: permite espaço para baterias maiores de 80Wh a 90Wh.
⚠️ Descontinuado Baia para HD / SSD SATA 2.5"

Praticamente nenhum notebook gamer moderno possui baia interna SATA de 2.5".

  • ❌ Espaço foi eliminado para caber baterias maiores e câmaras de vapor com tubos de cobre duplos.
  • 💡 Como usar meu HD antigo? Compre um case externo USB 3.0 (R$ 35) e ligue via USB como HD externo!
